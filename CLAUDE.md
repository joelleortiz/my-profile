# Notes for agents

## Structure

- `src/lib/scene/`: the canvas scene, plain TypeScript with no Svelte. `engine.ts` renders; `layout.ts` types `art/scene.json`; `palettes.ts`, `materials.ts`, `color.ts` and `recolor.ts` handle palette swaps; `lighting.ts`, `sky.ts` and `dither.ts` the lighting; `sprites.ts` reads Aseprite sheets; `time.ts` the time of day.
- `src/lib/scene/art/`: sprite sheets (generated by `npm run art`, or exported from Aseprite), `scene.json` and the frozen key palette. `ART_SPEC.md` documents all of it for artists.
- `src/lib/theme/`: palette and time-of-day state shared by the scene and the page chrome. `head.ts` is injected into `<head>` by `hooks.server.ts` so the right palette paints first.
- `src/lib/components/`: the Svelte UI. Components import scene and theme modules, never the reverse.
- `src/lib/cv.ts`: the CV content, copied word for word from `prompts/cv.json` without the phone number.
- `src/lib/audio/`: owned by the music work. Only call its public API (`setSoundOn`, `isSoundOn`, `playSceneSound`, `setTimeOfDay`).
- `scripts/art/`: Node scripts that draw every sprite from editable pixel data and regenerate the tables in `ART_SPEC.md`. They import `palettes.ts`, `color.ts`, `materials.ts`, `layout.ts` and `sprites.ts` directly.

## Conventions

- Import local TypeScript with its `.ts` extension (`#lib/scene/engine.ts`, `./color.ts`). Node runs `scripts/art` with type stripping, which needs the extension and only accepts erasable syntax: no enums or parameter properties in modules the scripts import.
- The render order is the `draw` list in `scene.json`. Lights screen over what has been drawn so far, masked to opaque pixels, and the far layer goes behind last, so the sky is never tinted or lit.
- Whole-number scaling is done in CSS (`--u` is one device pixel; `round()` snaps the scene width). Keep the canvas at 480 × 270 and let CSS scale it.
- Text colours must meet WCAG AA on `bg` and `surface` in every palette and mode; the `ui` tokens in `palettes.ts` are tuned for that.

## Dev-only hooks

- `?palette=retro&time=dusk` overrides the palette and time of day.
- `window.__theme` (set `override` to a time of day) and `window.__scene` (`play(sprite, tag)`, `setFlag(flag, on)`) help check animations and crossfades from the console.
