# Notes for agents

## Structure

- `src/lib/scene/`: the canvas scene, plain TypeScript with no Svelte. `engine.ts` renders; `layout.ts` types `art/scene.json`; `palettes.ts`, `materials.ts`, `color.ts` and `recolor.ts` handle palette swaps; `lighting.ts`, `sky.ts` and `dither.ts` the lighting; `sprites.ts` reads Aseprite sheets and plays tags; `time.ts` the time of day; `director.ts` is the behaviour (who does what and when, clicks, the coffee level), driving the engine through `play`, `pose`, `wait` and flags.
- `src/lib/scene/fit-view.js` (typed through `viewport.ts`): picks the layout and a whole-number device-pixel scale for the viewport. The wall objects (sign, corkboard, clock, swatch card, window) sit differently in the `landscape` (desktop), `portrait` (phone) and `short` (phone held sideways) layouts; the desk set doesn't move, except the radio (a `radio` place: at the laptop's corner on phones, where only the middle of the desk is in view). The scale is the largest at which a layout's focus fits, never below 2 CSS px per scene pixel (below that the room is cropped around the text and switchers) and never so small that the view runs past the world. It fits the small viewport height (`100svh`, the address bar shown) and the canvas covers the large one (`100lvh`), so a phone's address bar sliding in or out never re-fits the scene; only width or real size changes do. It is plain JavaScript because the head script inlines its raw text to lay out before paint.
- `src/lib/content.ts`: homepage copy (heading and short bio), separate from `cv.ts`.
- `src/lib/scene/art/`: sprite sheets (generated by `npm run art`, or exported from Aseprite), `scene.json` and the frozen key palette. `ART_SPEC.md` documents all of it for artists.
- `src/lib/theme/`: palette and time-of-day state shared by the scene and the page chrome. Visitors change them with the wall clock and the paint-swatch card (`Switchers.svelte`), which call `theme.nextTime()` (follow your clock, then morning, day, dusk, night) and `theme.nextPalette()`; `setOverride()` and `setPalette()` save the choice in localStorage (`scene-time`, `scene-palette`). `head.ts` is injected into `<head>` by `hooks.server.ts` and reads those keys, so the saved palette and time paint first.
- `src/lib/components/`: the Svelte UI. Components import scene and theme modules, never the reverse.
- `src/lib/cv.ts`: the CV content, copied word for word from `prompts/cv.json` without the phone number.
- Sounds: tag events in the sheets (Aseprite user data) reach the director, which calls an injected `sound` callback; `Scene.svelte` forwards known events to `playSceneSound`. Sound is on by default: `Radio.svelte` shows `wantsSound()` (the saved choice, else on) and calls `startSoundAtFirstGesture`, which starts sound at the first click, tap or key press outside the radio, since browsers block audio until then. Once the scene has loaded, `Scene.svelte` calls `preloadMusic`, which downloads the loop when the page is idle (not with Data Saver or on 2G) so the first gesture only decodes it. Clicking the radio calls `chooseSound`, which applies the choice and saves it in localStorage (`sound`). The radio also keeps `setTimeOfDay` in step with the theme. Music and crackle keep playing in a background tab; only the purr stops.
- `src/lib/audio/`: owned by the music work. Only call its public API (`setSoundOn`, `isSoundOn`, `wantsSound`, `chooseSound`, `startSoundAtFirstGesture`, `preloadMusic`, `playSceneSound`, `setTimeOfDay`).
- `static/scene-dusk.png` and `static/og.png`: the still the page shows without JavaScript (in a `<noscript>`, so browsers running scripts never fetch it) and the 1200 × 630 Open Graph image, with the sign's lettering in it. `node scripts/still/capture.mjs`, with the dev server running, captures both; run it again after changing the art or the sign's words. The Open Graph and Twitter tags are in `src/routes/+page.svelte`.
- `static/favicon.ico`, `favicon.svg` and `apple-touch-icon.png`: Myles's head, drawn from pixel data in `scripts/art/icons.ts` and written by `npm run art`.
- `scripts/art/`: Node scripts that draw every sprite from editable pixel data and regenerate the tables in `ART_SPEC.md`. `sprites/study.ts` holds the camera and projects the room and desk set (`lib/project.ts`); `sprites/parts.ts` draws Joelle, the cats and the props; `node scripts/art/study-positions.ts` prints where the projected sprites go in `scene.json`. They import `palettes.ts`, `color.ts`, `materials.ts`, `layout.ts` and `sprites.ts` directly.

## Conventions

- Import local TypeScript with its `.ts` extension (`#lib/scene/engine.ts`, `./color.ts`). Node runs `scripts/art` with type stripping, which needs the extension and only accepts erasable syntax: no enums or parameter properties in modules the scripts import.
- The render order is the `draw` list in `scene.json`. Lights screen over what has been drawn so far, masked to opaque pixels, and the far layer goes behind last, so the sky is never tinted or lit.
- The engine renders the whole world offscreen and copies the camera's view to a viewport-sized canvas. In-room HTML (`.in-scene`, `.in-room`) is placed in world pixels: `--s`, `--cam-x` and `--cam-y` on `<html>` become `--sp` (one scene pixel in CSS px) and `--ox`/`--oy` (where the world's origin lands); `data-layout` on `<html>` names the layout, and `.in-room` elements carry a position per layout (`placeVars()` in `layout.ts`). Their text is sized in `--tu` (a scene pixel, capped at 3 px) and coloured `--paper-ink`. Without JavaScript, `layout.css` sets the same variables from the still's cover fit, so on wide enough screens the sign and corkboard sit on their boards; otherwise they stack as cards.
- The room never moves. Only the view outside the window (the `far` layer: sky, clouds, city) shifts with the pointer or the touch drift, and not at all with reduced motion. The room is opaque everywhere except the window glass, which `scene.json` cuts out, and the sky is composited only inside that cut.
- Joelle is four sprites at different depths: `me` (behind the desk), `me-arms` (Joelle's forearms in front of it) and `me-hand` (Joelle's hand on Myles's head, in front of him), which `follow` `me` frame for frame so all three sheets need the same frames, and `me-face` (blink and glint overlays on `me`'s `face` slice). The director starts the coffee's `sip<level>` with `me`'s `sip` so the cup moves with Joelle's hand, and Myles leans into the hand on the `pet-start` event. With reduced motion it holds poses, and only Joelle and Myles blink.
- Tooltips (`.scene-tip`) open on hover, keyboard focus and `.tapped`. A tap leaves `:hover` stuck, so after touch input (`data-input="touch"` on `<html>`, kept by `Scene.svelte`) hover no longer opens them.
- Only the stickers that are links (GitHub, LinkedIn, and the CV once it exists) are interactive; the other stickers are plain art with no element.
- Text colours must meet WCAG AA on `bg` and `surface` in every palette and mode; the `ui` tokens in `palettes.ts` are tuned for that.

## Dev-only hooks

- `?palette=retro&time=dusk` overrides the palette and time of day for that page load (read by the head script and `theme`), without saving.
- `window.__theme` (set `override` to a time of day) and `window.__scene` (`play(sprite, tag)`, `pose`, `setFlag(flag, on)`) help check animations and crossfades from the console. Both are compiled out of production builds.
